# Contributing

Read `AGENTS.md` and `constitution.md` first. Open an issue for hardware claims or architecture changes. Use a focused `codex/<feature>` branch, include tests and documentation, update the constitution for every code-changing pull request, and request a reviewed diff before merging.

Do not include credentials, recordings, captured images, private conversation data, generated Xcode user state, or code copied from VisionClaw without a documented license review.
