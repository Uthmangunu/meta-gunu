# ADR-0001: clean-room implementation and MIT license

Status: accepted, 2026-09-18.

Meta Gunu is inspired by VisionClaw but begins without copying its application source. The inspected VisionClaw repository includes terms that must not be assumed to be an open-source grant for arbitrary redistribution. A clean-room start makes ownership and review boundaries explicit.

New Meta Gunu code is MIT-licensed. Any future upstream import requires a separate license review, attribution record, and pull request that identifies every imported file and its governing terms.
